# glm-design-system

The GLM design lab: the kitchen sink, prototypes for internal and user testing, and proposed updates to the design system. Deployed at https://glm-design-system.netlify.app/.

The rules for what GLM ships live in `GLM.Web/DESIGN-SYSTEM.md` in the Foundant/glm repo. The kitchen sink loads production CSS live from beta and layers this repo's proposals (`glm-prototype-foundation.css`) on top. See `CLAUDE.md` for how the repo is organized.
